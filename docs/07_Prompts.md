# Prompts

## Landing Page Prompt

Build a dark basketball recruitment landing page for Canadian Prospects Recruitment using red `#CC0000` and black `#0A0A0A`. The page should communicate opportunity, coach visibility, profile organization, and school fit. Use the headline `YOUR NEXT OPPORTUNITY STARTS HERE.` with `OPPORTUNITY` on its own line.

## Athlete Profile Summary Prompt

Create a concise recruiting summary for this athlete using the provided profile data. Mention sport, position, height, weight, graduation year, school, GPA, strengths, and target opportunity type. Keep the tone professional and coach-ready.

## Coach Outreach Email Prompt

Write a short email from Canadian Prospects Recruitment to a college coach introducing an athlete. Include athlete name, position, class year, school, GPA, key strengths, highlight link, and a request for evaluation. Keep it direct and respectful.

## Parent Follow-Up Prompt

Write a clear parent follow-up email confirming that the athlete application was received. Explain that CPR will review profile details, film, academics, and recruiting fit. Include next steps and a reminder to provide missing documents if needed.

## Missing Materials Prompt

Write a reminder message asking the athlete or parent to upload missing recruiting materials. Mention acceptable materials: mixtapes, game film, YouTube links, photos, team details, transcripts, report cards, awards, and other documents.

## Success Story Prompt

Write a short success story for a Canadian Prospects Recruitment athlete who earned a college opportunity. Include athlete name, school, challenge, process, and result. Keep the story authentic and concise.

## Admin Notes Prompt

Summarize this athlete record for CPR staff. Highlight profile completeness, strengths, missing information, academic fit, outreach readiness, and recommended next status.
