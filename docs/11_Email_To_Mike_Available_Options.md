Subject: CPR site options

Mike,

Here are the current CPR site options:

- Home page: Explains CPR, shows proof photos, camps, Play To Win, and sends athletes to apply.
- Apply: Athletes/parents submit profile details, film links, academics, uploads, agreement acknowledgement, and contact info.
- Public player profiles: Shareable athlete pages for coaches to review.
- Admin portal: Log in, view applicants from Airtable, filter/search athletes, open profiles, and update status.
- Password reset help: Lets you request admin password help by email.
- Help links: Each main feature now has a direct help option that opens an email to CPR support.

Template options shown on the site but not fully wired yet:

- Coach Outreach, Resource Hub, Event & Camp Hub, Parent Portal, Payments, Ask CPR, Messaging, Documents, and Pulse Dashboard.

How to use it:

Send athletes to Apply, review them in Admin, update their status, share public profiles with coaches, and use the help links whenever a feature or record needs support.

Short answer on wiring:

Apply, admin, password help, and player profiles are wired now; the broader portal options are available as template modules but still need to be connected into the live portal.
